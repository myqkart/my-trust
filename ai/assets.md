# Purpose

Every image, illustration, icon, SVG, video, texture, pattern, animation, and downloadable file must follow one unified visual identity.

The website should feel handcrafted—not assembled from random assets.

# AI Asset Rules

Whenever selecting or generating assets

- Prefer authentic photography over illustrations.
- Use real images whenever available.
- Keep all decorative elements subtle.
- Follow the approved color palette.
- Optimize every asset before use.
- Reuse existing SVGs and illustrations whenever possible.
- Never introduce inconsistent illustration styles.
- Every image should support the story being told.
- Every decorative asset should enhance, not distract.

The complete asset library should feel like it was curated by a professional brand and creative direction team, with every visual element contributing to a cohesive, premium, and emotionally engaging experience.
