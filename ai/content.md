# Content Strategy & Copywriting Guidelines

---

# Purpose

This document defines how all website content should be written.

The goal is not to create marketing content.

The goal is to build trust.

Every sentence should help visitors understand, believe, and emotionally connect with the trust.

The writing should feel genuine, compassionate, and inspiring.

Never sound like advertising.

---

# Content Philosophy

The website should never ask for donations first.

It should first:

Build empathy

↓

Show authenticity

↓

Demonstrate transparency

↓

Prove impact

↓

Create confidence

↓

Then invite participation.

People donate because they trust.

Not because they are asked.

# AI Content Rules

Whenever AI generates content

Never invent facts.

Never invent statistics.

Never invent awards.

Never invent beneficiaries.

Never invent donor names.

Never invent stories.

Use placeholders when real information is unavailable.

Example

{{FOUNDER_NAME}}

{{TRUST_NAME}}

{{YEARS_OF_SERVICE}}

{{TOTAL_RESIDENTS}}

{{TOTAL_VOLUNTEERS}}

{{TOTAL_DONATIONS}}

{{REGISTRATION_NUMBER}}

{{MISSION_STATEMENT}}

Replace placeholders only when verified data is available.

# Content Quality Checklist

Before publishing any content ensure

✓ Human sounding

✓ Emotionally engaging

✓ Easy to understand

✓ Factually accurate

✓ Inclusive

✓ Accessible

✓ SEO friendly

✓ Free of repetition

✓ Action oriented

✓ Trust building

✓ Inspirational

✓ Transparent

Every paragraph should answer one simple question:

"Does this help the visitor trust us more?"

If the answer is no, rewrite it.

The purpose of every word on this website is to strengthen trust, inspire compassion, and encourage meaningful action.
