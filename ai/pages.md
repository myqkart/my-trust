# Website Pages & Experience Architecture

---

# Purpose

This document defines every page of the website.

Every page must have

• One clear purpose
• One emotional objective
• One primary CTA
• Strong storytelling
• Premium visuals
• Consistent spacing
• Beautiful transitions
• Responsive layouts
• Accessibility
• SEO optimization

No page should exist only to provide information.

Every page should move the visitor closer to trust and participation.

# AI Rules

Whenever generating any page:

- Maintain visual consistency with `design.md`
- Follow the writing principles from `content.md`
- Reuse components instead of creating duplicates
- Keep each page focused on a single objective
- Every page must contain at least one trust-building section
- Every page must end with a strong CTA
- Every page should include subtle animations, decorative SVG elements, layered backgrounds, and responsive layouts
- Ensure every experience feels premium, emotionally engaging, and worthy of an award-winning modern website.
